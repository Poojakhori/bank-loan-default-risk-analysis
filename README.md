# 🏦 Bank Loan Default Risk Analysis using SQL

## 📌 Project Overview

This SQL project analyzes a bank's loan portfolio to identify default patterns, borrower risk segments, and portfolio performance. The analysis helps financial institutions understand the factors contributing to loan defaults and supports data-driven lending decisions.

## 🎯 Objectives

* Analyze the overall loan portfolio.
* Calculate loan default rates across different customer segments.
* Identify high-risk borrower categories.
* Evaluate loan performance by region, income band, employment type, and credit grade.
* Generate business insights using SQL queries.
